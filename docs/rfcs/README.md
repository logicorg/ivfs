# Requests for comments

An RFC records an idea that is still under discussion: the problem, the
options considered so far, and the questions left open. It decides nothing.

When a direction is chosen, the decision is written up as an ADR in
[`docs/adrs`](../adrs), and the RFC's status is set to point to it. An RFC that
is dropped stays here with its status set to "Withdrawn", so the reasoning is
not lost.
